## 1. At a glance


| Area                     | What you can do                                                                          |
| ------------------------ | ---------------------------------------------------------------------------------------- |
| **Avatar videos**        | Turn a script into a presenter-led video, edit scene by scene, and export a finished MP4 |
| **AI presentations**     | Generate a full slide deck from a prompt, then edit, present, share, and export          |
| **Manual presentations** | Build decks slide by slide with charts, tables, media, and AI writing help               |
| **Canvas editor**        | Design on a custom-size canvas and export as image or SVG                                |
| **AI images**            | Create visuals from text, refine them, save, and share                                   |
| **Avatars & voices**     | Digital twin, photo avatar, or prompt-based avatar; voice clone and voice design         |
| **Brand kits**           | Logos, colors, typography, imagery, buttons, and guidelines                              |
| **Workspaces**           | Personal and team folders, roles, shared credits, and a shared asset library             |
| **Admin**                | User and workspace oversight, storage requests, templates, reports, and email broadcast  |


**Typical video workflow:** Log in → Dashboard → Create Avatar Video → Editor → Add scenes & media → Configure presenter → Generate → Preview → Download MP4

## 5. AI avatar video editor

Compose multi-scene avatar videos with in-editor preview and cloud rendering for the final MP4.

### Project & scenes


| Feature                  | Description                                                         |
| ------------------------ | ------------------------------------------------------------------- |
| **Multi-scene projects** | Add, duplicate, delete, and reorder scenes                          |
| **Quick Create**         | Set presenter, look, and voice for the first scene (or skip)        |
| **Auto-save**            | Edits are saved as you work                                         |
| **Scene settings**       | Duration, background, presenter, and transitions                    |
| **Transitions**          | Dissolve, slide, wipes, match & move, flow, stack, chop, and more   |
| **Aspect ratios**        | Primary 16:9; other ratios and custom sizes available in the wizard |




### Presenter


| Feature                   | Description                                              |
| ------------------------- | -------------------------------------------------------- |
| **Per-scene avatar**      | Choose an avatar and look for each scene                 |
| **Per-scene voice**       | Choose a voice; speed Slow, Normal, or Fast              |
| **Narration script**      | Script drives lip-synced presenter video                 |
| **Generate / regenerate** | Create the presenter clip for a scene and track progress |
| **Credits display**       | See remaining credits while generating and exporting     |




### Insert & canvas tools


| Feature              | Description                                                                       |
| -------------------- | --------------------------------------------------------------------------------- |
| **Images & videos**  | Insert media layers                                                               |
| **Upload**           | JPEG, PNG, WebP, MP4, and MP3 (up to 50 MB per file)                              |
| **Stock media**      | Browse and import stock photos and video                                          |
| **Text**             | Text layers with inline editing                                                   |
| **Graphics**         | Shapes, icons, and frames                                                         |
| **Layer editing**    | Drag, resize, rotate; smart guides; snap, grid, safe zone, and zoom               |
| **Layer properties** | Position, animations, order, fit/flip, looks (e.g. brightness), borders, and fill |
| **Audio layers**     | Volume, fade, and timing                                                          |




### Timeline, preview & export


| Feature                | Description                                                                             |
| ---------------------- | --------------------------------------------------------------------------------------- |
| **Timeline**           | Play/pause, tracks, scene or full timeline, zoom                                        |
| **Undo / redo**        | Step through your editing history                                                       |
| **Preview**            | Play scenes, layers, and presenter clips in the editor                                  |
| **Export / download**  | Choose filename, resolution (e.g. 720p, 1080p, 4K), and quality — then download the MP4 |
| **Project comments**   | Comments and @mentions with notifications                                               |
| **Keyboard shortcuts** | Common shortcuts for play, undo, save, export, and frame stepping                       |
